# Curvy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Curvy, a Windows tray app that drives Equalizer APO. It searches AutoEQ, builds headphone profiles with a per-profile preference and a universal preference layered on top, and lets you switch profiles from the tray.

**Architecture:**
- `Curvy.Core` is a UI-free .NET 11 class library. It holds all logic: filter math, layer chain and preamp, the APO config reader/writer, the AutoEQ index/search/fetch, persistence, and an orchestrating `CurvyEngine`.
- `Curvy.App` is a thin WinUI 3 app written with Microsoft UI Reactor (created from the Reactor template, unpackaged). It renders state from the engine and calls engine methods.
- `Curvy.Core.Tests` (xUnit) covers Core. UI tasks are verified by running the app.

**Tech Stack:**
- C# on .NET 11.
- `Microsoft.UI.Reactor` (preview) on WinUI 3 / Windows App SDK.
- ScottPlot.WinUI for the graph, with a Win2D fallback.
- System.Text.Json and xUnit.

**Spec:** `docs/superpowers/specs/2026-11-24-curvy-design.md`

## Global Constraints

- Windows only. Target framework is `net11.0-windows10.0.22621.0` for App and Core, and the tests use the same TFM.
- The app is **unpackaged** (`WindowsPackageType=None`) and must run unelevated. If the APO folder isn't writable, report it and never elevate.
- **Output only.** Nothing touches microphones or capture devices.
- Curvy owns `<APO config>\Curvy\curvy.txt` and exactly one line in `config.txt`: `Include: Curvy\curvy.txt`. It never deletes other lines. Disabling a line comments it out with the prefix `# [Curvy] `. Before the first change to `config.txt`, Curvy writes a backup to `config.txt.curvy-backup`.
- Every file Curvy writes into the APO folder is written atomically (temp file, then replace).
- All number formatting and parsing uses `CultureInfo.InvariantCulture`.
- Data lives under `%LocalAppData%\Curvy\`: `settings.json`, `profiles\{id}.json`, and `autoeq\`. Every JSON file has `"schemaVersion": 1`.
- AutoEQ data comes from `https://raw.githubusercontent.com/jaakkopasanen/AutoEq/master/results/` (`INDEX.md`, plus `… ParametricEQ.txt` per result). The User-Agent is `Curvy/<version>`. The About section credits AutoEq (MIT license).
- Graph and preamp math run at a 48 kHz sample rate over 20 Hz to 20 kHz.
- Default tone controls: bass low shelf 105 Hz, Q 0.7. Treble high shelf 10 kHz, Q 0.7. Tilt pivot 1 kHz. Slider range ±12 dB in 0.1 dB steps.
- Leave out device linking, hotkeys, an installer, and code signing. Keep `CurvyEngine.Activate` callable from anywhere so hotkeys can be added later.

## Review Focus

1. **Comma-decimal Windows locale (the user is likely on de-DE).** Writing `Gain 7,4 dB` breaks APO without any error, and parsing AutoEQ's `7.4` as 74 does the same. Pinned by `Formatter_UsesInvariantCulture_UnderGermanLocale` and `Parser_UsesInvariantCulture_UnderGermanLocale` (Task 3).
2. **`config.txt` already touched by Peace or by hand.** The Curvy include may already be there with different casing, forward slashes or extra spaces, or there may be duplicates. The file may be missing or end without a newline. Curvy must stay idempotent and never add a second include. Pinned by `EnsureCurvyInclude_IsIdempotent_AcrossVariants` and `EnsureCurvyInclude_CreatesConfigTxt_WhenMissing` (Task 5).
3. **Large stacked boosts, all-cut curves, and a narrow peak between grid points.** The preamp must cover the true maximum, so a narrow high-Q boost can't slip between sample points, and the preamp must be 0 when everything cuts. Pinned by `Preamp_CoversNarrowPeakBetweenGridPoints`, `Preamp_IsZero_WhenAllCuts` and `Preamp_StacksAllLayers` (Task 4).
4. **No network on first AutoEQ search, or a corrupt cache.** The user needs a clear "can't reach AutoEQ" state rather than a crash, and a corrupt cache must be refetched. Pinned by `GetIndex_Throws_AutoEqUnavailable_WhenOfflineAndNoCache` and `GetIndex_Refetches_WhenCacheCorrupt` (Task 10).
5. **One broken or future-version profile file.** It must not take down the profile list. Pinned by `LoadAll_SkipsCorruptAndFutureVersionFiles` (Task 7).
